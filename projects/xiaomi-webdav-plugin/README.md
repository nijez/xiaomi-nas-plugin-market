# WebDAV 文件桥 0.2.0-rc5

第三方测试版，非小米官方。仅在自有且已开启密钥 SSH 的 NAS 上使用。从插件市场安装，共享默认关闭，不修改小米出厂 5000 端口 WebDAV。

## 功能

- NAS 文件夹通过独立 HTTPS WebDAV 服务共享，每账号对每目录选择不可访问、只读或读写，默认拒绝访问。
- 账号存于插件独立权限配置，不创建 Linux 用户或修改小米账号；密码至少 8 字符，英文大小写、数字、半角符号中至少两类。
- 目录选择器可新建文件夹；单击名称打开、双击原位改名，回车保存、Esc/失焦取消。改名影响实际路径，外部应用的旧路径不会自动更新。
- 账号根目录、一级目录、配置引用目录及其祖先禁止改名；共享开启或备份运行时不允许改名。同名不覆盖，拒绝越界与符号链接。
- 远程连接用于 NAS 与其他 WebDAV 服务之间的上传、下载和定时单向备份。开启 NAS 共享不会自动创建远程连接或备份任务。
- 备份使用 rclone copy，不传播源端删除；覆盖前尝试保留旧版本到目标 `.webdav-history`。不承诺并发编辑快照或所有服务都支持断点续传。

## 安装与连接

从插件市场安装后，先添加共享目录、账号及授权，再显式开启共享。使用远程备份前，先配置远程服务 URL 和该服务自己的账号密码。

管理服务监听 NAS `127.0.0.1:18120`，小米客户端使用同源设备入口；共享端口为 `18121`，仅绑定检测到的局域网 IPv4 地址。首次开启会生成每台 NAS 独立证书，在客户端信任自己 NAS 的 CA 后连接。不要忽略证书校验，不要做公网端口映射。

原单账号配置只在用户显式确认时导入为 `/legacy/`，旧客户端映射须增加这个路径；不自动转换或开启共享。

## 权限与升级

配置位于 `/data/plugin/webdav/data`，与版本化程序分离。权限文件 0600、目录 0700；新用户密码为 PBKDF2-SHA256 加盐哈希。旧共享配置和远程连接凭据仍依赖文件权限保护，不声称已经加密。

服务以安装账号运行。会检查固件、内核/Python、UID、根目录和授权目录的身份，变化时拒绝共享。官方 OTA 可能覆盖 systemd、nginx 或注册信息，也可能影响数据保留；不能保证升级无影响。执行 `scripts/check_after_upgrade.py` 可只读检查，确认环境和原目录后再开启，不自动放宽权限。

## 构建与测试

纯 Python 依赖及其许可证已随源码提供，ARM64 rclone 在安装包内，不进入 Git 历史。获取方法见根目录 BUILD.md。

```bash
python3 scripts/prepare_vendor.py
node scripts/build_ui.cjs
RCLONE_BINARY=/path/to/local/rclone python3 -m unittest discover -s tests -v
```

Mac MicroApp 将脚本分别放入独立函数作用域，因此 app.js 与 access-ui.js 必须合并为 app.bundle.js 加载，不能恢复成两个入口。使用本地 PNG data URL 保持动态图标兼容。

已验证的局部测试不等于所有固件、实体 Windows、多用户高并发、真实 OTA 或外部远程服务兼容性通过。root 和同一宿主账号进程属于受信本机边界。
