# Mac plugin window layout correction

## Observed failure

The real Mac client embeds this page in a `micro-app` element. Its body is
rewritten to `micro-app-body`; the surrounding `.frmcontainer` has a fixed
height and `overflow: hidden`. The original plugin body grew to its content
height without providing an inner scrollbar. The five catalog entries were
loaded, but the last three were clipped.

The host document also had a computed root font size of 39.2px. The original
`:root` rule did not establish a font size inside the embedded plugin. Tabs,
buttons and version labels inherited the host size.

## Correction

- Added an explicitly sized, keyboard-focusable `#community-store-app` scroll
  region, within a body that fills the host's allocated height.
- Set the plugin's font, colors and custom properties on its own root instead
  of relying on the host document root. Gave buttons and version labels explicit
  sizes; kept the back and refresh glyph sizes.
- Added container-width breakpoints for a narrow plugin window inside a wide
  desktop client. Standalone/mobile viewport breakpoints remain available.
- Updated the stylesheet URL to `0.1.2-layout1` to avoid the old cached CSS.
- No API, authorization, package catalog, installed data or service changes.

## Verification

- `python3 -m unittest discover -s tests -v`: 10 tests passed.
- `node --test tests/layout.test.cjs`: eight layout cases passed, standalone
  and simulated micro-app hosts at 1280, 760, 393 and 320px widths. Requires
  Playwright with its Chromium browser installed. `NODE_PATH` can point to an
  existing development installation; no new production dependency is added.
- Checks cover computed font sizes, horizontal containment, column count,
  wheel scrolling to the final card in featured/installed views, tab switching,
  image loading and preservation of the simulated host's 39.2px root font.
- Real Mac client: reproduced non-scrolling before the correction, reloaded
  only this plugin after the update, then scrolled to the final Aliyun card.
  The installed view also displayed its entries and controls correctly.
- Android physical-device retest remains outstanding. Mobile-width browser
  checks are not equivalent to Android client acceptance.

## Local NAS update

Only `web/index.html` and `web/styles.css` were updated on the existing local
NAS installation. Original files were retained as `before-index.html` and
`before-styles.css` under
`/data/plugin/community-store/backups/layout-20260905-0108/`.
The server remained active; no NAS, container or service restart was needed.

Source correction is not a published release: no commit, GitHub push,
re-signing of release artifacts or installer publication was performed.
