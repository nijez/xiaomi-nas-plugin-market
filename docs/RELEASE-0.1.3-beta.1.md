# 插件市场 0.1.3-beta.1 公开测试

这是可下载运行的一键安装包，不是源码压缩包。非稳定版、非小米官方产品。

## 下载与安装

下载 `xiaomi-plugin-market-0.1.3-beta.1.zip` 和 `SHA256SUMS.txt`，核对 SHA-256 后完整解压。

- Windows：双击 `install-windows.cmd`，需系统 OpenSSH 客户端。
- Mac：运行 `install-macos.command`；被系统拦截时在终端运行 `bash install.sh`，不要关闭系统安全保护。
- Linux / 终端：在解压目录运行 `bash install.sh`。

按提示填写当前 NAS IP、自己的 root SSH 私钥和 NAS 用户。设备必须已 root 并启用密钥 SSH；本包不提供 root 工具或任何个人密钥。电脑和 NAS 须在同一局域网。完成后重新打开小米客户端，在全部应用找到插件市场。

## 本包包含

- 插件市场 0.1.3-beta.1：Windows 命令转义修复、统一安装回滚流程、身份鉴权加固、滚动与窗口布局修复。
- 设备管家 0.4.2-beta.1。
- 115 云备份 0.1.1-beta.1：携带已在 RP05 验证的 ARM64 离线依赖和固定哈希 pip 引导文件，不在 NAS 联网构建依赖。
- 阿里云盘备份 0.1.1-beta.1：鉴权和下载冲突保留修复。
- WebDAV 文件桥 0.2.0-rc6、qB 下载 0.1.0-rc2：纳入共享鉴权加固后重新打包。

五个插件包、仓库清单均重新签名。单个 `.bundle.zip` 不是 Windows 安装器；首次使用应下载完整市场 ZIP。

## 已验证与已知限制

已在 ARM64 容器及 RP05 Python 3.12.4 上验证完整依赖离线安装，以及真实 OSS SDK 的本地 1 MiB 模拟上传。不是实际云盘账号上传验收。

Windows 10/11 完整安装待测试者反馈。Mac/Android 的 token/中继身份闭环未完成，缺少可信证书身份时可能拒绝访问；不应关闭鉴权来绕过。普通安装失败会尝试回滚并保留备份，但断电/SIGKILL 自动恢复尚未实现。进程权限进一步隔离仍在开发中。qB 首次启动需下载独立 Docker 镜像；云盘插件需要各自已批准的应用资料。

只建议保留 SSH 恢复能力的用户参加测试，安装前备份配置；不建议在唯一备份设备上首测。此发布不主动升级维护者在线 NAS，也不承诺官方固件升级后始终兼容。

## 提交反馈

在仓库 Issues 附上安装包版本、NAS 型号/固件、Windows 或 Mac 版本、客户端版本、复现步骤和脱敏报错。不要上传私钥、令牌、账户配置或业务文件。遇到失败先保留安装日志和 NAS 备份，不要反复覆盖安装或删除恢复材料。
